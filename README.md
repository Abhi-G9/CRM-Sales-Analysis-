# CRM Sales Analysis Project

This project contains SQL queries and analysis designed to extract business insights from a CRM sales dataset. 
The dataset includes information about deals, sectors, products, regional offices, managers, and sales agents. 
The goal of this project is to practice converting real-world business problems into data-driven KPIs and queries.

## Key Features
- Sector-wise Lost and Won deals analysis
- Regional office performance comparison
- Product-wise revenue ranking
- Sales agent efficiency and performance metrics
- Average deal closing time (Won vs Lost)
- Monthly revenue trends
- Repeat customer identification

## Purpose
This repository is created as part of my learning journey in data analysis and SQL. 
It demonstrates how to translate business questions into queries and generate actionable insights.

## Tools Used
- SQL (MySQL)

## How to Use
1. Run the SQL queries on your CRM dataset.
2. Explore the KPIs and adapt queries for your own analysis.
